# Coding Guidelines

- Keep the app simple, focused, and maintainable. Prefer small, clear changes over unnecessary abstractions.
- Use React, Vite, and TypeScript for application work.
- Do not add backend services, cloud integrations, or external APIs unless explicitly requested.
- Keep walkthrough content in local JSON files under `src/data/games/`.
- Use only original or appropriately licensed content. Do not add copyrighted game text, images, logos, maps, or copied guide material.
- Preserve the spoiler-mode system and localStorage-based progress tracking when changing related features.
- Run the project's type checks before finishing (currently `npm run lint`).
- Update `README.md` when changing setup, walkthrough-data structure, or major features.
- After each task, summarize changed files and any known limitations.
